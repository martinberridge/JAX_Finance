# JAX PV01 port

## Module map

`pv01_jax.arrays` defines Equinox pytree containers for swap legs, swaps, curve
specifications, and calibration problems. Static names, labels, and slices
describe model structure; JAX arrays hold the numerical values.

`pv01_jax.resolve` converts resolved trades and loaded calibration data into
those array structures, preserving quote and curve-node order. It also
provides NumPy reference calculations used to check the conversion.

`pv01_jax.interp` implements linear, double-quadratic, and natural-cubic-spline
interpolation in JAX. `pv01_jax.curves` builds named curves from calibrated
parameters and provides zero rates, discount factors, forwards, and period
compounding.

`pv01_jax.pricers` computes fixed-versus-floating swap PV and calibration
residuals from the array models. `pv01_jax.calibrate` solves those residuals
with a JAX Newton iteration; `jax.lax.custom_root` supplies implicit
differentiation, and the module also exposes convergence diagnostics and a
checked calibration variant.

`pv01_jax.risk` exposes zero-rate PV01, market-quote PV01, parallel PV01,
cross-gamma, batched per-trade PV01, and aggregate portfolio PV01. Sensitivities
are returned in GBP per basis point (and cross-gamma in GBP per bp squared).

## From the hand-coded reverse pass to JAX

| Hand-coded calculation | JAX calculation |
| --- | --- |
| `DiscountingSwapTradePricer.present_value_sensitivity` in `pv01_pricer/swap_pricer.py`, producing `PointSensitivities` defined in `pv01_pricer/rates_provider.py` | `jax.grad` of `pv_swap` in `pv01_jax/pricers.py` / `pv01_jax/risk.py` |
| `ImmutableRatesProvider.parameter_sensitivity` in `pv01_pricer/rates_provider.py` | Automatic differentiation through the interpolator in `pv01_jax/interp.py` |
| `JacobianCalibrationMatrix` in `pv01_market/jacobian.py` and `MarketQuoteSensitivityCalculator` in `pv01_pricer/market_quote_sensitivity.py` | Implicit differentiation through `jax.lax.custom_root` in `pv01_jax/calibrate.py` |

## Running it

Run commands from `pv01/`. To run the complete unittest suite:

```bash
python -m unittest discover -s tests -t .
RUN_SLOW=1 python -m unittest discover -s tests -t .
```

`RUN_SLOW=1` enables the opt-in hand-coded bump-and-recalibrate comparison.
The NCS reference-correctness bump test is particularly slow. To run only the
frozen golden regression test:

```bash
env -u RUN_SLOW python -m unittest -v tests.jax_port.test_frozen_goldens
```

Run the JAX calibration and risk example, which writes to
`target/example-output-jax/`:

```bash
python pv01_examples/jax/calibration_interpolation_example_jax.py
```

Write the frozen JAX risk goldens:

```bash
python pv01_examples/jax/write_jax_goldens.py
```

Run the risk benchmark. The NCS hand-coded bump timing is skipped unless
`--slow` is supplied:

```bash
python -m benchmarks.real_config
python -m benchmarks.real_config --slow
```

## Known differences from Strata

The Strata comparison has not been run; `target/strata_comparison.md` is not
present. The Python port has known convention simplifications that may affect
agreement:

- Schedule periods are generated by `generate_schedule` in
  `pv01_basics/schedule.py` and adjusted using the configured calendar.
- OIS floating cashflows are compounded period by period rather than with
  daily overnight fixings.
- Payment dates are calendar-adjusted by the schedule generator; full Strata
  payment-date conventions are not modeled.
- Forward rates are calculated from period start/end dates; index fixing-date
  conventions are not modeled separately.
